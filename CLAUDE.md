# Hafıza Oyunu

Arapça harflerle kart eşleştirme oyunu. Tek sayfa web uygulaması.

## Kurallar
- Vanilla HTML/CSS/JS, framework yok
- Tek dosya: `index.html` (CSS ve JS inline)
- Mobil öncelikli tasarım
- Arapça font: Google Fonts Amiri
- Karanlık tema, altın aksanlar
- localStorage ile skor kayıt
- Türkçe arayüz
